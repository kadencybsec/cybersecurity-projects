# Evidence standard

A completed project needs all of the following:

- A useful **result**: small runnable example, investigation, report, diagram or research output.
- **Reproduction steps** that another learner could follow safely.
- An **original explanation** of what each important command or choice does.
- **Evidence** (sanitised screenshots, sample logs, tests or citations), linked in `data/progress.json`.
- A **limitation** and one sensible next improvement.
- No real credentials, personal information, unapproved IPs, private challenge flags or unlicensed content.

The calendar is for scheduling, the JSON registry is for measured progress, and the README is for communicating learning.
