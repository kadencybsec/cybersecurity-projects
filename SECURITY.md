# Security policy and safe testing

This is a learning portfolio. All tests are confined to devices I own or systems with explicit authorisation, isolated virtual machines, synthetic datasets and official training labs. Any published outputs are sanitised. No production attack code, private keys, passwords, access tokens, actual phishing deliveries, real DDoS traffic, malware payloads or active CTF spoilers are accepted.

Use GitHub's private vulnerability-reporting interface if enabled; otherwise do not post sensitive exploit details publicly. Real third-party vulnerabilities should follow the owner's disclosure process. Do not publish real personal or school network information.
